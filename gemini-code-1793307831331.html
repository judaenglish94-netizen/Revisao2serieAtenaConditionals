Conditionals in Context

First, Second & Third Conditionals + Pontuação (Vírgulas) - 2ª Série EM

📌 A Regra de Ouro das Vírgulas nas Condicionais!

• Com vírgula: Se a frase começa com a oração subordinada (If-clause), deve haver vírgula separando as orações.
👉 If you study hard, you will pass the exam.

• Sem vírgula: Se a oração principal (com will / would / would have) vier primeiro, NÃO usaremos vírgula antes do "If".
👉 You will pass the exam if you study hard.

1. First Conditional (Possibilidades Reais no Futuro)

Usada para situações possíveis ou prováveis no presente/futuro.

• Estrutura: If + Simple Present ➔ Will + Verbo Base

• Exemplo com vírgula: If it rains tomorrow, we will stay at home.

• Exemplo sem vírgula: We will stay at home if it rains tomorrow.

2. Second Conditional (Hipóteses Irreais no Presente/Futuro)

Usada para situações imaginárias, improváveis ou conselhos no presente.

• Estrutura: If + Simple Past ➔ Would + Verbo Base

Lembrete: Na linguagem formal, usamos 'Were' para todos os pronomes (If I were, If he were).

• Exemplo com vírgula: If I won the lottery, I would travel the world.

• Exemplo sem vírgula: I would travel the world if I won the lottery.

3. Third Conditional (Arrependimentos / Passado Impossível)

Usada para imaginar um resultado diferente para algo que já aconteceu no passado.

• Estrutura: If + Past Perfect (had + V3) ➔ Would have + Participio (V3)

• Exemplo com vírgula: If she had studied, she would have passed the test.

• Exemplo sem vírgula: She would have passed the test if she had studied.
